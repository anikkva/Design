# Design

Репозиторий сейчас находится в минимальном стартовом состоянии.

## Текущее состояние
- Инициализирован git-репозиторий.
- В корне есть только служебный файл `.gitkeep`.
- Прикладного кода, конфигурации сборки и тестов пока нет.

## Что это значит для новичка
1. **Архитектуры пока нет**: нет модулей, папок `src/`, `tests/`, `docs/` и т.д.
2. **Точка входа не определена**: нет исполняемого приложения/библиотеки.
3. **Нужно определить стек**: язык, фреймворк, менеджер зависимостей, CI.

## Что стоит сделать дальше
- Добавить `README` с целями проекта, setup-инструкцией и roadmap.
- Создать базовую структуру проекта под выбранный стек.
- Настроить линтер/форматтер и минимальный CI.
- Добавить первые smoke-тесты.

## Быстрые подсказки для старта
- Если это веб-проект: определить frontend/backend, схему API, окружения.
- Если библиотека: определить публичный API, семантику версий и changelog.
- Зафиксировать правила в `CONTRIBUTING.md` и шаблонах issue/PR.
